[text] Loading Design Rules
[text] Use skeletons when the page structure is known.
[text] Use small spinners for button actions.
[text] Use medium spinners for section-level requests.
[text] Use large spinners only for appropriate initial loading situations.
[text] Never use multiple unnecessary spinners in one small component.
[text] Never invent progress percentages.
[text] Never show an infinite loading state as a normal completed screen.
[text] Never use loading visuals to represent an error or empty state.
